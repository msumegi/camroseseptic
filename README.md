# camroseseptic.ca
Hosting: GitHub Pages, repo msumegi/camroseseptic, main branch root, custom domain via CNAME.
Form backend: FormSubmit.co (free, no account). Leads go to msumegi@gmail.com with a CC to rangeroadtech+septic@mail.grokbot.com (bot logs them). First submission triggers a one-time activation email to msumegi@gmail.com; click "Activate Form". Afterwards swap the email in the form action for the random alias FormSubmit gives, to hide the address from scrapers.
Spam: _honey honeypot field + _blacklist phrases + FormSubmit's default reCAPTCHA.
Pages: / (home), /services/, /service-area/, /septic-tips/ (FAQ and tips), /request/ (the form). Thank-you page: thanks.html (noindex, not in the sitemap). /demo/front-desk/ stays unlinked and out of the sitemap. SEO: robots.txt, sitemap.xml, a canonical on each page, JSON-LD Organization + WebSite + Service on the home page (Service repeated on /services/), FAQPage on /septic-tips/. No street address and no business phone, by design. Old home anchors #form and #quote go to /request/.
Search Console: URL-prefix property https://camroseseptic.ca/, HTML-file method; commit the google*.html file Google provides to the repo root.
Target: septic pumping Camrose & Camrose County (Camrose, Bawlf, New Norway, Hay Lakes, Kingman, Round Hill, Bittern Lake, Ohaton, Daysland, Tofield); secondary: Stettler County. Keep all copy to Camrose County and Stettler County only.
